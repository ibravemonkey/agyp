# agyp ⚡

> **Изоляция мульти-аккаунтов, статусная строка телеметрии в реальном времени и автоматизация рабочего пространства для Google Antigravity CLI (`agy`).**

`agyp` — это расширенный инструмент и менеджер профилей для `agy`. Он обеспечивает бесшовное переключение профилей, мониторинг квот нескольких аккаунтов Google (5-часовых и недельных), песочницу без загрязнения глобальной системы, а также статусную строку с отслеживанием веток Git, жизненного цикла AI-агентов и системных звуковых уведомлений.

---

## ✨ Возможности и улучшения

### 1. 🖥️ Статусная строка телеметрии в реальном времени (HUD)
Отображается в нижней части терминала во время сессий Antigravity CLI, разделяя контекст проекта, квоты и детальную телеметрию токенов без обрезания текста:
```text
[agy1] · 📦 my-project ·  main ·  Idle · 12% ctx
gemini-3.8-flash (high) · 5H: 84% (1h14m) · Week: 72% (3d8h) ·  179.2/s
```

**Строка 1 (Контекст и рабочее пространство):**
- **Тег профиля:** Высококонтрастный бейдж профиля (`[agy1]`).
- **Определение проекта:** Автоматически определяет текущую рабочую директорию (`📦 my-project`).
- **Отслеживание веток Git:** Автоматически сканирует дерево каталогов и определяет активную ветку или detached HEAD (` main`). Поддерживает обычные репозитории и Git worktrees.
- **Индикатор состояния агента:** Визуальный индикатор на основе Nerd Font:
  - ` Working` (желтый) — Агент активно обрабатывает запрос или генерирует код.
  - `󰧑 Thinking` (бирюзовый) — Рассуждения / планирование модели.
  - ` Waiting` (желтый) — Ожидание ввода или подтверждения от пользователя.
  - ` Done` (зеленый) — Задача завершена.
- **Контекстное окно:** Процент заполнения контекстного окна модели (`12% ctx`).

**Строка 2 (Модель, квоты и скорость):**
- **Модель и уровень рассуждений (effort):** Активная модель и установленный уровень reasoning effort (`gemini-3.8-flash (high)`).
- **5-часовой лимит:** Остаток квоты и таймер до восстановления (`5H: 84% (1h14m)`).
- **Недельный лимит:** Остаток недельной квоты (`Week: 72% (3d8h)`).
- **Скорость генерации:** Скорость генерации токенов в секунду (` 179.2/s`).

### 2. 🔔 Звуковые и системные уведомления об окончании работы
- Когда агент завершает задачу (`Working`/`Thinking` ➔ `Done`), `agyp` отправляет:
  - Нативное системное звуковое уведомление (например, `Glass.aiff` на macOS / системный звук на Linux).
  - Терминальный сигнал привлечения внимания (`\a` + последовательность OSC-уведомлений, поддерживаемая Ghostty, iTerm2, WezTerm, Kitty).
  - Системный баннер уведомления рабочего стола.
- Полная переносимость: автоматический поиск скрипта через `$AGYP_NOTIFY_SOUND_SCRIPT`, `~/.gemini/config/bin`, `~/.local/bin` или `$PATH`.

### 3. 🎯 Интерактивный TUI-селектор возобновления сессий (`agyp resume`)
- Интерактивный выбор ранее запущенных диалогов с навигацией стрелками или клавишами `j`/`k`.
- Поиск на лету (клавиша `/`), группировка по проектам (`Ctrl+F`), быстрый переход по номерам `1-9`.
- Автоматическая миграция контекста диалога между профилями без потери истории.

### 4. 🧠 Умный запуск и авто-переключение аккаунтов (`agya`, `agyp auto`, `--auto`)
- **Авто-выбор при старте**: выбор профиля с максимальным доступным остатком 5-часовой квоты Gemini из всех подключенных аккаунтов.
- **Бесшовное переключение сессий при 429**: если квота текущего аккаунта исчерпана, при продолжении (`agy -c` или `agya -c`) сессия автоматически переносится на свободный аккаунт без потери контекста и файлов `brain`.
- **In-flight воркер квот**: при исчерпании лимита во время диалога воркер выводит статус в футер терминала (`⚡ 429: квота исчерпана -> готов agy2 (100%)`) и превентивно подкладывает свежий токен.
- **Мгновенная команда `agya`**: супер-быстрый запуск под лучшим аккаунтом (`agya` для нового диалога, `agya -c` для продолжения).
- Флаг `--all` (`-a`) для последовательного выполнения команд сразу на всех настроенных профилях.
### 5. 🤖 AI-ассистированные коммиты (`agyp commit`)
- Интеллектуальный анализ staged-файлов в Git через выбранный профиль.
- Автоматическая проверка кода (code review), детекция потенциальных уязвимостей и секретов.
- Генерация или валидация коммит-сообщения по стандартам Conventional Commits с возможностью подтверждения или ручного редактирования.

### 6. 🩺 Диагностика окружения (`agyp doctor`)
- Полный аудит здоровья окружения: проверка бинарников `agyp` и `agy`, валидность OAuth-токенов, изоляция macOS Keychain, доступность каталога моделей и RPC-сокетов Herdr.

### 7. 🌐 Удаленная работа через SSH (`agyp ssh`)
- Бесшовное подключение к удаленному Linux-серверу с выделением PTY.
- Автоматический локальный HTTP CONNECT прокси для туннелирования API-запросов (обход геоблокировок).
- Автоматическая синхронизация токенов авторизации на удаленный хост и запуск удаленного `agyp`/`agy`.

### 8. 📊 Визуальный дашборд квот (`agyp quota` / `agyq`)
Интерактивный терминальный дашборд с индикаторами заполнения квот:

### 9. 🔄 Автоматическая синхронизация скиллов, MCP, темы и тулчейнов (`agyp sync`)
- **Автоматически из-под капота**: при создании аккаунта (`agyp add`) и перед каждым запуском (`agyp run`) все настройки базового окружения автоматически подключаются в профиль:
  - **Тема оформления и предпочтения**: автоматическое наследование `colorScheme` (например, `tokyo night` / `dark`), `agentMode`, `permissions`, `trustedWorkspaces` из вашего `~/.gemini/antigravity-cli/settings.json` — Antigravity больше не спрашивает выбор темы при первом входе.
  - **Встроенная статусная строка**: автоматическая привязка хука `"statusLine": {"command": "agyp statusline-hook"}`.
  - **Навыки (Skills)**: `~/.gemini/config/skills` и `skills.json` — любые установленные скиллы сразу доступны во всех профилях.
  - **MCP Серверы**: `mcp_config.json` и слияние `mcpServers` из основного `settings.json` (например, сервера баз данных, filesystem и др.).
  - **Инструменты оптимизации**: `rtk`, `sqz`, `skill-compass`, директивы `GEMINI.md`, правила `rules/` и хуки `hooks.json`.
  - **Окружение разработчика**: доступ к `.local/bin`, `.cargo`, `.ssh` и `.gitconfig` внутри изолированной песочницы профиля.
- **Ручная синхронизация**: команда `agyp sync` (с флагом `-q` для тихого режима).

### 10. 🧹 Умная очистка и дисковая гигиена по TTL (`agyp clean` / `prune`)
- **Удаление по TTL**: очистка устаревших сессий диалогов (`brain/<conv_id>/`) старше заданного срока (по умолчанию `14d`, поддержка `7d`, `30days`, `48h`, `2w`).
- **Защита недавних диалогов (`--keep-last`)**: гарантированное сохранение последних $N$ сессий (по умолчанию 5) независимо от их возраста, защищая от случайной потери актуального контекста.
- **Очистка временных кэшей и логов**: автоматическое освобождение места от `ide-data/logs`, `Crashpad`, `crashes`, `Caches`, `.cache`, зависших блокировок `.agyp.lock`.
- **Синхронизация истории**: автоматическая очистка удаленных диалогов из `history.jsonl` и кэша сессий `agyp resume`.
- **Безопасный режим симуляции (`--dry-run` / `-n`)**: предварительный расчет освобождаемого пространства без изменения файлов на диске.
- Флаг `--all` (`-a`) для пакетной очистки всех профилей сразу.

### 11. 🔐 Защищенный перенос и шифрование профилей (`agyp export --encrypt` / `import`)
- **Стандарт безопасности Zero-Trust**: шифрование архивов профилей современным алгоритмом **AES-256-GCM** с криптографической аутентификацией целостности данных.
- **Надежная деривация ключей**: **PBKDF2-HMAC-SHA256** (100 000 итераций) со случайной солью (16 байт) и уникальным nonce (12 байт).
- **Контейнер `AGYP_ENC`**: автоматическое распознавание зашифрованных архивов при `agyp import` с запросом пароля.
- **Защита учетных записей**: безопасная пересылка и бэкап Google OAuth токенов и конфигураций на удаленные серверы или между рабочими станциями.
- Поддержка интерактивного скрытого ввода пароля, флага `--password` или переменной окружения `AGYP_ENCRYPTION_KEY` для CI/CD.

### 12. 🛡️ Санитизация окружения и устранение DA2-артефактов
- **Устранение фантомных символов `0;0c[>1;0;0c`**: движок Antigravity (ultraviolet) при запуске через SSH или в некоторых терминалах шлет запросы `\x1b[>c` (Device Attributes 2). `agyp` автоматически вычищает переменные `SSH_CLIENT`, `SSH_CONNECTION`, `SSH_TTY` (сохраняя `SSH_AUTH_SOCK` для Git).
- **Принудительное определение `TERM_PROGRAM`**: терминал представляется как современный мультиплексор (`ghostty`, `herdr`, `agyp`), предотвращая несинхронизированные зонды терминала.

### 13. 🔄 Фоновое авто-обновление с ненавязчивыми уведомлениями
- **Detached Background Worker**: при выполнении команд `agyp` периодически (раз в 6 часов) запускает легковесный фоновый процесс проверки релизов на GitHub с `flock`-блокировкой.
- **Безопасная атомарная замена**: бинарник скачивается в фоне, проходит ad-hoc codesigning на macOS и атомарно заменяется.
- **Информационное уведомление**: при следующем вызове CLI выводится сообщение: `[agyp] Automatically updated to vX.Y.Z in background!`.
- **Настройка через переменные**: возможность отключения (`AGYP_NO_AUTO_UPDATE=1` или `CI=1`) и изменения интервала (`AGYP_UPDATE_INTERVAL=12h`).

### 14. 🗄️ Полная миграция сессий и SQLite БД диалогов (`agyp migrate`)
- **Бесшовный перенос диалогов**: миграция не только каталогов `brain/<conv_id>`, но и соответствующих SQLite баз данных (`conversations/<conv_id>.db`, `.db-wal`, `.db-shm`), аннотаций (`annotations/*.pbtxt`) и сводок (`conversation_summaries.db`).
- **Детекция сессий**: мгновенное нахождение диалогов по отдельным базам данных SQLite и очистка stale presence locks.

### 15. ⚡ Высокопроизводительный движок (HTTP/2, пул сокетов, TTL-кэши)
- **HTTP/2 Connection Pooling**: пул постоянных соединений (`MaxIdleConnsPerHost: 20`, HTTP/2 multiplexing) ускоряет получение квот и проверку почты в 2–3 раза.
- **Дедупликация I/O в статуслайне**: проверка идентичности состояния предотвращает до 90% холостых перезаписей на диск при стриминге ответа.
- **In-Memory TTL кэш ветки Git**: кэширование ветки на 3 секунды устраняет глубокое сканирование каталогов при каждом рендере строки.
- **Мульти-панельный broadcast квот в Herdr**: автоматическое обновление индикаторов квот во всех сплитах и панелях без повторных RPC-запросов.

### 16. 🕒 График расхода токенов за день / неделю (`agyp stats` / `agys` / `agypq`)
- **Мгновенная аналитика активности**: наглядное отображение ежедневного расхода токенов (Input, Output, Cached, Total) с ASCII-барами активности.
- **Разбивка по аккаунтам и моделям**: детальная статистика, сколько токенов потребил каждый профиль (`agy1`, `agy2`, `work`) и каждая модель (`gemini-3.8-flash`, `claude-opus-4-6-thinking`).
- **Быстрые команды**: вызов через `agyp stats`, `agys` или `agypq`.
- **Гибкие фильтры**: флаг `--days 14` (за 14 или 30 дней), `--profile work` (фильтр по аккаунту), `--json` (для скриптов).

## 🚀 Пошаговое руководство: от установки до работы

### Шаг 1. Установка в 1 команду
Склонируйте репозиторий и запустите скрипт установки:
```bash
./install.sh
```
Скрипт автоматически:
1. Компилирует оптимизированный бинарник `agyp` и помещает его в `~/.local/bin/agyp`.
2. Создает исполняемые команды `agy` и `agyq` в `~/.local/bin`.
3. Настраивает ваш файл оболочки (`~/.zshrc` или `~/.bashrc`), прописывая путь к бинарникам и системные функции.
4. Восстанавливает команды для ранее созданных профилей (если они уже были).

Примените изменения в текущем окне терминала:
```bash
source ~/.zshrc    # или source ~/.bashrc
```

---

### Шаг 2. Подключение Google-аккаунтов (`agyp add`)
Добавьте ваши аккаунты один за другим. Например, `agy1`, `agy2`, `work` и т.д.:
```bash
agyp add agy1
```
**Что произойдет автоматически:**
1. Создается изолированная песочница `~/.agyp/profiles/agy1/`.
2. Открывается браузер для входа в ваш Google-аккаунт через Google OAuth (`agy login`).
3. Вы входите в аккаунт в браузере.
4. `agyp` перехватывает токен, сохраняет его в защищенное хранилище и выводит подтверждение:
```text
● Создание изолированного профиля agy1...
● Открываем браузер для авторизации Google OAuth (`agy login`)...

✓ Авторизация успешна: user1@gmail.com

✨ Мгновенные команды созданы в ~/.local/bin (доступны без перезапуска):
  ● agy1   — запуск Antigravity CLI под этим профилем
  ● use1   — переключить профиль по умолчанию на agy1

Готово! Вы можете сразу набрать agyq для проверки квот или начать работу.
```

Аналогично добавьте второй и последующие аккаунты:
```bash
agyp add agy2
agyp add agy3
```

### Шаг 4. Мгновенный запуск и переключение аккаунтов

Вам больше **не нужно** вводить длинные команды или перезапускать терминал. Прямо в текущем окне работают мгновенные команды:

```bash
# 1. Прямой запуск под первым аккаунтом:
agy1

# 2. Прямой запуск под вторым аккаунтом:
agy2

# 3. Запуск с флагами или конкретным промптом:
agy1 -m gemini-3.8-flash --dangerously-skip-permissions

# 4. Включение полностью автоматического режима (рекомендуется):
agyp use auto      # agyp теперь ВСЕГДА сам выбирает свободный аккаунт
agy                # запуск Antigravity на лучшем аккаунте
agy -c             # продолжение сессии с авто-ротацией при исчерпании лимита

# 5. Мгновенные команды с авто-квотой:
agya               # быстрый запуск под лучшим аккаунтом
agya -c            # продолжить сессию под лучшим аккаунтом

# 6. Ручное переключение активного аккаунта по умолчанию:
use2               # переключает активный аккаунт на agy2
agy                # запускает Antigravity под agy2

# 7. Поведение при 429 (исчерпании квоты):
# - В футере сразу загорается бейдж: "⚡ 429: квота исчерпана -> готов agy2 (100%)".
# - Нажмите Enter, чтобы повторить запрос с подмененным токеном.
# - Либо нажмите Ctrl+C и введите `agy -c` — сессия бесшовно продолжится на agy2.

### Шаг 5. Настройка оболочки отдельной командой (`agyp setup-shell`)
Если вы хотите перенастроить интеграцию или перенесли бинарники:
```bash
# Автоматическая настройка:
agyp setup-shell

# Полное удаление настроек agyp из .zshrc / .bashrc:
agyp setup-shell --uninstall
```

## 🛠️ Справочник основных команд

### Управление профилями
```bash
# Создание нового профиля с авторизацией
agyp add work

# Список всех профилей
agyp list
agyp list -q                # с подробной информацией о квотах

# Установка профиля по умолчанию (или auto для полной автоматизации)
agyp use auto               # автоматический выбор аккаунта с лучшей квотой
agyp use agy1               # фиксация конкретного профиля
agyp use --unset            # сброс профиля по умолчанию

# Быстрый авто-запуск
agya                        # эквивалент agyp run --auto
agya -c                     # продолжение сессии на свободном аккаунте
# Удаление профиля (выход из аккаунта и удаление токенов)
agyp delete agy1
agyp delete -f agy1         # принудительно без запроса подтверждения

# Полный сброс всех аккаунтов и шимов
rm -rf ~/.agyp/profiles/* && agyp setup-shell

# Клонирование существующего профиля
agyp clone agy1 agy1-backup
### Запуск сессий
```bash
# Запуск с активным профилем по умолчанию
agyp run -- --dangerously-skip-permissions

# Запуск с указанным профилем
agyp run work

# Автоматический выбор профиля по наибольшей квоте
agyp auto

### Защищенный экспорт и импорт профилей (Export / Import)
```bash

## 🔒 Безопасность и изоляция

- **Полная изоляция данных:** Токены авторизации, конфигурации, контексты сессий и настройки каждого аккаунта хранятся строго изолированно в `~/.agyp/profiles/<name>/`.
- **Изоляция Keychain:** На macOS ключи доступа изолируются в отдельных файлах связки ключей профиля.
- **Шифрование архивов (Zero-Trust):** Экспорт профилей поддерживает алгоритм **AES-256-GCM** и деривацию ключа **PBKDF2-HMAC-SHA256** (100k итераций) со случайной солью и nonce, гарантируя конфиденциальность и целостность токенов при переносе.
- **Безопасность Git:** Команда `agyp commit` автоматически обнаруживает токены и секреты в коде и блокирует авто-коммит, требуя явного подтверждения.
