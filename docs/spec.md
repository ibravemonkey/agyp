# Спецификация: Antigravity CLI Switcher (`agyp`)

## Цель
`agyp` (Antigravity CLI Switcher) — утилита командной строки на языке Go, предназначенная для управления изолированными профилями нескольких аккаунтов инструмента `agy` CLI (Google Antigravity). Изоляция достигается динамическим переопределением переменной окружения `HOME` при запуске `agy` на изолированные каталоги профилей `~/.agyp/profiles/<profile_name>/`.

## Стек технологий
- Язык: Go (Golang) 1.22+
- CLI фреймворк: `github.com/spf13/cobra`
- Сборка и релизы: GoReleaser + GitHub Actions
- Инсталлятор: POSIX-совместимый скрипт оболочки (`install.sh`)

## Архитектура и структура пакетов
```text
agyp/
├── cmd/                     # Тонкий слой команд Cobra (парсинг флагов, вызовы internal)
├── internal/                # Приватная бизнес-логика и интерфейсы
│   ├── runner/              # Запуск процессов agy, резолв моделей и квот
│   ├── doctor/              # Проверки целостности окружения и генерация отчетов
│   ├── selector/            # Интерактивный TUI-селектор диалогов
│   ├── sshproxy/            # Локальный HTTP CONNECT прокси и SSH-сессии
│   ├── gitops/              # Git-операции и AI-коммиты
│   └── shell/               # Управление шимами (~/.local/bin) и интеграция с оболочкой (.zshrc)
├── pkg/                     # Переиспользуемые библиотеки
│   ├── profile/            # Работа с файловой структурой профилей, токенами и квотами
│   ├── updater/            # Механизм самообновления
│   └── version/            # Информация о версии
├── docs/                    # Документация и спецификации
├── tasks/                   # Планы задач
├── install.sh               # Скрипт установки
├── main.go                  # Точка входа
└── go.mod
```

## Команды и подкоманды
- `agyp add <profile_name>`:
  - Валидация имени профиля (буквы, цифры, дефис, подчеркивание).
  - Создание каталога `~/.agyp/profiles/<profile_name>` с наследованием базовых настроек (тема, разрешения, воркспейсы).
  - Автоматическая привязка `statusLine` хука.
  - Запуск браузерного OAuth `agy` (без лишних аргументов) с подключением к `os.Stdin`, `os.Stdout`, `os.Stderr`.
  - Автоматическое создание мгновенных команд в `~/.local/bin` (`agy1`, `use1`, `<name>`) с точной нумерацией и обновление `.zshrc`.
- `agyp list` (псевдоним `ls`):
  - Сканирование каталога `~/.agyp/profiles/`.
  - Отображение списка настроенных профилей (с флагом `-q` — с подробными квотами).
- `agyp delete <profile_name>` (псевдоним `rm`):
  - Запрос подтверждения у пользователя `[y/N]` (или пропуск с флагом `-f` / `--force`).
  - Удаление каталога `~/.agyp/profiles/<profile_name>` с выходом из аккаунта и очисткой токенов.
  - Автоматическая очистка связанных шимов команд в `~/.local/bin` и обновление конфигурации оболочки.
- `agyp sync [profile_name]`:
  - Синхронизация скиллов, MCP-серверов, темы (`colorScheme`), разрешений (`permissions`), хуков, плагинов и тулчейнов из базового окружения.
  - Флаг `-q` для тихого режима.
- `agyp run [profile_name] -- [agy_commands...]`:
  - Запуск `agy` в изолированном каталоге профиля.
  - Поддержка авто-профиля по максимальной квоте (`auto`), флага последовательного запуска на всех профилях (`--all` / `-a`), автоматической инъекции модели и reasoning effort.
- `agyp use [profile_name]`:
  - Установка или отображение активного профиля по умолчанию (`~/.agyp/current`).
  - Флаг `--unset` (`-u`) для сброса профиля по умолчанию.
- `agyp auto`:
  - Запуск с профилем, имеющим максимальный остаток 5-часовой квоты Gemini.
- `agyp resume [query]`:
  - Интерактивный TUI-селектор недавних диалогов со стрелочной навигацией, поиском и группировкой по проектам.
- `agyp commit [profile_name] [flags]`:
  - Анализ изменений Git через AI, проверка безопасности кода (секреты, токены), генерация и подтверждение коммит-сообщения.
- `agyp doctor`:
  - Комплексный аудит системы: бинарники, OAuth-токены, Keychain, каталог моделей, Herdr RPC.
- `agyp setup-shell` (псевдонимы `setup`, `init-shell`):
  - Автоматическая настройка `.zshrc` / `.bashrc` с добавлением `PATH` и функций.
  - Создание базовых исполняемых команд `agy` и `agyq` в `~/.local/bin` с защитой от перезаписи оригинального бинарника `agy`.
  - Синхронизация мгновенных команд для всех существующих профилей (с точной привязкой `agy<N>` к `agy<N>`).
  - Поддержка флага `--uninstall` (`-u`) для чистой деинсталляции.
- `agyp ssh <server> [path] [profile] -- [commands]`:
  - Удаленное выполнение на Linux-сервере через SSH с туннелированием API через локальный прокси.
- `agyp plugin <install|list|uninstall> [target] [--all]`:
  - Управление плагинами agy для одного или всех профилей.
- `agyp quota [profile_name]` (псевдоним `q`):
  - Мониторинг квот моделей (5-часовых и недельных).

- `agyp clean [profile_name]` (псевдоним `prune`):
  - Очистка старых сессий (`brain/<conv_id>/`) по критерию TTL (`--ttl` / `--older-than`, дефолт `14d`).
  - Защита от удаления последних сессий (`--keep-last`, дефолт 5).
  - Очистка временных кэшей (`ide-data/logs`, `Crashpad`, `crashes`, `Caches`, `.cache`).
  - Синхронное удаление очищенных сессий из `history.jsonl` и кэша сессий.
  - Режим симуляции (`--dry-run` / `-n`) и пакетная очистка всех профилей (`--all` / `-a`).
- `agyp export [profile_name]`:
  - Экспорт профиля или всех профилей (`--all` / `-a`) в tar.gz архив.
  - Опциональное шифрование архива (`--encrypt` / `-e`) по стандарту AES-256-GCM + PBKDF2-HMAC-SHA256 (контейнер `AGYP_ENC`).
- `agyp import <archive_path> [target_profile_name]`:
  - Восстановление профиля или всех профилей (`--all`).
  - Авто-определение зашифрованного архива `AGYP_ENC` с безопасным запросом пароля и потоковой расшифровкой в памяти.
## Статусная строка телеметрии (statusLine HUD)
- **Строка 1 (Окружение):** Профиль (`[agy1]`), рабочая папка (`📦 name`), git-ветка (` branch`), статус агента (`🟢 Idle`), процент контекстного окна (`12% ctx`).
- **Строка 2 (Модель, лимиты и производительность):** Модель и reasoning effort (`gemini-3.8-flash (high)`), 5-часовой лимит с таймером сброса (`5H: 84% (1h14m)`), недельный лимит (`Week: 72% (3d8h)`), скорость генерации (` 179.2/s`).
- **Сохранение потоков I/O:** Полное сохранение пользовательского терминала (TTY/PTY) при запуске `run`, `ssh` и `add`.
- **Точная адресация профилей:** Профили формата `agy<N>` строго привязываются к командам `agy<N>` и `use<N>`, исключая ошибки смещения по индексу.
- **Безопасность:** Запрос подтверждения при удалении каталогов. Блокировка авто-коммита при обнаружении секретов.
- **Изоляция:** Модификация файлов разрешена только внутри каталога целевого профиля.
