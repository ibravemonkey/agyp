# План реализации: Набор команд `agys plugin`

**Цель:** Реализовать выделенный набор подкоманд `agys plugin` (`install`, `list`, `uninstall`) с компактным выводом и поддержкой нескольких профилей через `--all` / `-a`.

**Архитектура:** Создание `cmd/plugin.go` с описанием подкоманд Cobra `pluginCmd`, `pluginInstallCmd`, `pluginListCmd`, `pluginUninstallCmd`. Функция-помощник `execPluginCmd` запускает `agy plugin <action> <args>` с установкой `HOME` в каталог каждого профиля, кратко форматируя вывод.

**Стек:** Go (Cobra CLI, `os/exec`).

## Глобальные ограничения
- Использовать `rtk` для git и команд оболочки.
- Сохранять изоляцию профилей путем установки `HOME=<profileDir>`.
